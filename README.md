# Œil curieux — quiz en images

Application monopage réalisée avec Vue 3 et JavaScript. Le quiz présente cinq images locales; chaque question propose trois réponses et une bonne réponse ajoute un point. La progression est affichée pendant la partie, puis le score final peut être rejoué.

Les illustrations sont des fichiers SVG locaux dans `public/images`. Les questions et la logique sont définies dans `src/App.vue`. Aucune base de données, API ou ressource externe n’est utilisée.

## Démarrer

```sh
npm install
npm run dev
```

## Vérifier la compilation

```sh
npm run build
```
